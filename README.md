# Site · Dr. Matheus Jansen

Site em React + Vite, com o dente 3D em three.js.

- Desenvolvimento: `cd app`, `npm install`, `npm run dev`
- Versão final local: `npm run build` e `npm run preview`
- Publicação: todo envio para o `main` publica sozinho em https://yan791.github.io/site_matheusjansen/

Textos e contatos ficam em `app/src/data/content.ts`.
